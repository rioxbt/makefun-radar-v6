Every protocol the snapshot holds that records no token, ranked by the value its own record implies if one were issued — a fitted model, walk-forward tested, with every factor of every score printed and attributable.

    # Protocol Category Chains TVL 7d Tenure Implied value 90% band Class

    How a value is built. Each factor is a fitted weight in lib/calibration.json; the detail view prints every component with the snapshot field that fed it, so a score can be taken apart line by line. The model fits nothing here — it applies coefficients fitted offline by tools/fit-forecast.mjs.

    Where the data is from. One sealed snapshot of DefiLlama's protocol record (as of ), plus a corpus of real launches collected from DexScreener's public API by tools/fetch-dexscreener.mjs to check the model out of sample. DefiLlama's record is not proof: a row says a protocol records no token, never that it has none.

    What this is not. The implied value is this radar's own claim about what a token would be worth if the protocol's record stood as it does; it is not advice, it does not predict whether or when a token is issued, and the farm plans describe activity that may return nothing.
